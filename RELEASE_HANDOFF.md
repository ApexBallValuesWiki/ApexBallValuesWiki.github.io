# Release handoff — November 1, 2026

This archive contains source changes only. Neither the shared worker nor either hosted website was deployed as part of this update.

## What changed

- The landing hero rotates **only the 17 supplied images**, in their fixed supplied order, approximately every five seconds. The collection in `src/data/heroArtwork.js` is independent of the live unit database. The next image is decoded before the previous image fades out; slow or broken images do not leave an empty hero. Rotation pauses while the hero or browser tab is out of view and resumes on return. Previous, next and play/pause controls work on desktop and mobile.
- The desktop/mobile hero now uses the same 760 ms, matched-easing dissolve and gentle translation, without animated scaling. Cleanup follows transition completion with a safety timeout; rapid requests are queued rather than snapping or stacking layers. The hidden desktop scanline pauses while the hero is in view and resumes when it leaves view or the route changes.
- Desktop hero pictures use lossless, 2× presentation copies in `src/assets/units/hero-desktop/`, generated reproducibly by `node scripts/generate-hero-previews.mjs`. They retain the original alpha, mildly sharpen the existing raster and precompute the same grayscale/contrast/brightness treatment; the theme tint remains live. This is a modest presentation improvement, **not recovered source detail**. Mobile and any failed desktop WebP use the untouched supplied PNGs. The copies are decorative only and do not change normal or shiny unit artwork.
- System or site reduced-motion and the site's animation-off setting start the carousel paused. The visitor can explicitly play that carousel without changing the global setting; visual transitions remain disabled. The same motion preferences are applied to Framer Motion and the discovery deck.
- Supplied character cutouts are larger and distributed as page decoration across Home, Wiki, Values, Calculator, Minigames and Achievements. Their silhouettes follow the selected theme accent, including when the theme is changed live. These decorative images do **not** replace actual unit pictures: normal and shiny Wiki/Values images retain the existing explicit/live/cached/fallback lookup.
- The continuously repainted shader canvas was replaced with lightweight CSS plates, and the old silk shader on the maintenance screen was replaced with a static theme-aware field. Pointer tilt updates are limited to a single layer, and scroll-reveal discovery checks newly mounted subtrees instead of rescanning the entire application. Unit grids no longer have a per-item Framer stagger, and value gauges animate transforms rather than layout widths. Content stays visible even if reveal animations cannot run.
- Lenis provides eased wheel and anchor scrolling across routes while touch keeps native momentum and nested controls retain their own scrolling. System reduced motion, the site's reduced-motion and animation-off settings, and the smooth-scroll opt-out are respected. The non-overlapping 3D star field is lazy-loaded only on supported fine-pointer devices; touch, reduced-motion, scene-disabled and WebGL-failure cases use a static fallback.
- Ordinary copy is not selectable and text-specific hover changes are suppressed, as requested. Editable inputs, textareas and contenteditable fields remain selectable; controls retain their click, focus and keyboard behavior. Montserrat is used across the interface. Shared dropdowns and official MIT-licensed Coolicons are bundled; see `COOLICONS-LICENSE.txt`.
- Spreadsheet editing loads existing values, preserves unedited fields and notes, retains filtered edits and validates a batch before queueing it. Publishing is blocked until the coordinated worker update is available.
- The shared activity feed is separated from browser-local actions. The updated worker reports audit-write failures and archives entries before they leave its recent lists. A previous field snapshot can be applied from the log; that operation merges the prior fields and does not remove later-added fields.
